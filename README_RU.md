# UofsTg

UofsTg — это неофициальный клиент Telegram для iOS 6. Это форк проекта [Twelve](https://github.com/theanazerka/twelve-project), который в свою очередь основан на официальных исходниках Telegram для iOS.

UofsTg предлагает глубоко переработанный пользовательский интерфейс: мы полностью вырезали все элементы современного "плоского" дизайна 2019 года и жестко зафиксировали ультимативный скевоморфный стиль iOS 6 (2013 года) во всем приложении.

## ⚠️ Предупреждение о совместимости

UofsTg находится в разработке. Некоторые современные функции Telegram могут отсутствовать или работать нестабильно, поскольку клиент основан на старой кодовой базе и запускается на операционной системе 2012 года.

## Сборка UofsTg

Для сборки проекта вам понадобится среда с установленным [Theos](https://github.com/theos/theos) и iOS 6.0 SDK.

### Локальная сборка (macOS/Linux)
1. Склонируйте репозиторий вместе с субмодулями:
   ```bash
   git clone --recursive https://github.com/Uofi113/uofstg.git
   cd uofstg
   ```
2. Соберите `.deb` пакет:
   ```bash
   cd theos/Twelvium
   make package
   ```
3. Готовый пакет появится в папке `theos/Twelvium/packages`.

### Автоматическая сборка через GitHub Actions
В этом репозитории настроена автоматическая сборка UofsTg через GitHub Actions при отправке кода (push) в ветку `master` или `main`. Готовый `.deb` архив можно скачать во вкладке **Actions** на GitHub.

## Установка

Вы можете установить `.deb` пакет на джейлбрейкнутое устройство с iOS 6 через **iFile**, **Filza** или подключившись по SSH.
