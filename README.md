На iOS 27 (да ещё и на бетке!) менять что-то через Nugget — это прямо максимальная игра в русскую рулетку 💀

Во-первых, Nugget использует эксплойты в самой системе (типа SparseRestore), которые Apple постоянно латает. На бета-версиях свежих iOS файловая система и службы меняются с каждым апдейтом, так что гарантировать безопасность никто не сможет.

Вот чем это обычно грозит:

    Зацикленная перезагрузка (Bootloop): Самый классический исход. Nugget криво перепишет системный файл plist, отвечающий за конфиг оператора, и после перезагрузки девайс тупо зависнет на яблоке. Лечится только полным сбросом через recovery/DFU с потерей данных.

    Слёт мобильной связи: В худшем случае отвалится сотовая сеть/eSIM, и айфон перестанет видеть оператора вообще, пока не накатишь чистую систему.

    Бесполезность: В свежих апдейтах Apple часто принудительно перезаписывает или блокирует модификацию кастомных джобов и файлов конфигурации, так что имя оператора может просто сбрасываться обратно при первой же перезагрузке.

Вердикт: Это небезопасно. Если айфон 16 — твой основной девайс, лучше вообще не трогать Nugget на бета-версиях, иначе рискуешь остаться без связи и со сброшенным до заводских смартфоном. Оставь такие эксперименты своей четвёрке с iOS 6, её хотя бы восстановить — одно удовольствие)

# UofsTg


UofsTg is an unofficial Telegram client for iOS 6. It is a fork of [Twelve](https://github.com/theanazerka/twelve-project), which in turn is based on the official Telegram for iOS source code.


UofsTg brings a heavily refactored user interface that completely removes any modern "flat" design elements and forces an ultimate skeuomorphic iOS 6 style throughout the entire application.


## ⚠️ Compatibility Warning


UofsTg is a work in progress. Some modern Telegram features may be unavailable or unstable because the client is based on a legacy codebase and runs on an operating system released in 2012.


## Compiling UofsTg


To compile the project, you need an environment with the [Theos](https://github.com/theos/theos) toolchain and an iOS 6.0 SDK.


### Local Compilation (macOS/Linux)

1. Clone this repository with submodules:

```bash

git clone --recursive https://github.com/Uofi113/uofstg.git

cd uofstg

```

2. Build the `.deb` package:

```bash

cd theos/Twelvium

make package

```

3. The compiled `.deb` will be in `theos/Twelvium/packages`.


### Automated GitHub Actions Build

This repository is configured to automatically build UofsTg using GitHub Actions upon pushing to the `master` or `main` branch. Check the **Actions** tab on your GitHub repository to download the resulting `.deb` artifact.


## Installation


You can install the `.deb` package on a jailbroken iOS 6 device using **iFile**, **Filza**, or via SSH.
